## Global Shell & Keyboard Support

- **Header (`src/components/layout/StudioHeader.tsx`):** Brand mark + title, active Project dropdown switcher (with dirty-state confirmation dialog), Undo / Redo buttons (`Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z` / `Cmd/Ctrl+Y`), Unsaved Changes + Save indicator, top navigation (`Projects`, `Story`, `Studio`, `Render`), live `Healthy` / `Warning` / `Issues` diagnostics pill, Theme cycle button, `Preview`, and `Export MP4` / `Cancel Export`.
- **Left Rail (`src/components/layout/WorkspaceRail.tsx`):** Direct icon navigation for all 10 workspaces with `aria-current="page"` and `Alt+1..0` shortcuts.
- **Command Palette (`Cmd/Ctrl+K`, `src/components/layout/CommandPaletteDialog.tsx`):** Instant search across all 10 workspaces, workspace projects, and active project scenes.
- **Global & Editor Shortcuts:** `Cmd/Ctrl+S` (save draft), `Cmd/Ctrl+N` (new project dialog), `Cmd/Ctrl+Z` / `Cmd/Ctrl+Shift+Z` / `Cmd/Ctrl+Y` (undo/redo), `Space` (play/pause outside interactive controls/dialogs), `ArrowLeft` / `ArrowRight` (1-frame step outside interactive controls/timeline/rig pivots), `[` / `]` (toggle left/right Studio panels), `Delete`/`Backspace` (delete selected timeline clip), `Alt+1..0` (switch workspaces).
